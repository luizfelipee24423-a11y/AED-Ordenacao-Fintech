
# Ordenação de Transações Financeiras

Trabalho desenvolvido em C# para a disciplina de Algoritmos e Estruturas de Dados (AED) da PUC Minas.

## Objetivo

Simular transações financeiras e comparar o desempenho de três algoritmos de ordenação:

- Insertion Sort
- Merge Sort
- Quick Sort

## Funcionalidades

- Geração de transações aleatórias.
- Ordenação por valor crescente.
- Medição do tempo de execução.
- Exibição das 10 maiores transações.
- Salvamento dos resultados em CSV.

## Como executar

```bash
dotnet run -c Release
```
